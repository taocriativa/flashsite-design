# Validation Report — FlashSite Design 1.0.1

## Validações executadas

- `php -l` em todos os arquivos PHP do plugin.
- `node --check` nos arquivos JavaScript administrativos e de front-end.

## Pontos de teste recomendados

1. Confirmar que a seção “Modelo visual” não aparece mais no editor.
2. Confirmar que a sequência visual aparece como Texto, Imagens, Posição e leitura.
3. Confirmar que os controles de posição aparecem como cartões visuais com ícones, não como radios colados.
4. Confirmar que o cabeçalho das seções aparece em tom bege e o corpo dos campos em branco.
5. Confirmar que Barra de Aviso e Estilo Visual receberam a mesma inversão visual de cabeçalho/corpo.
6. Confirmar que banners já existentes continuam sendo renderizados no front-end.
