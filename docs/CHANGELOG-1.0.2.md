# FlashSite Design 1.0.2

## UX do editor de banners
- Padroniza a nomenclatura para Desktop/Tablet e Mobile, alinhando editor e preview.
- Substitui controles separados de esquerda/centro/direita e topo/centro/base por uma matriz visual 3×3 para posição do texto.
- Aplica destaque contextual: ao visualizar Desktop/Tablet, os controles de Mobile ficam discretos; ao visualizar Mobile, os controles de Desktop/Tablet ficam discretos.
- Mantém controle separado de foco da imagem por dispositivo.

## Botões
- Move as configurações essenciais de botão para uma seção própria no banner.
- Permite usar o botão padrão do FlashSite Design ou personalizar cor/formato por banner.
- Mantém controles técnicos de largura, respiro e cantos apenas em Ajustes avançados.

## Estilo visual
- Simplifica a página Estilo Visual para priorizar o botão padrão.
- Mantém configurações antigas em área avançada para compatibilidade.
