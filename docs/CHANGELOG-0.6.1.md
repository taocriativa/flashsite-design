# FlashSite Design 0.6.1 — Changelog

## Foco da versão
Refino de UX do painel Hero com edição por dispositivo ligada ao Live Preview Canvas.

## Entradas principais
- abas de dispositivo no topo do preview com modo de edição sincronizado
- exibição condicional dos blocos responsivos de desktop/tablet e mobile
- simplificação visual dos ajustes finos via bloco recolhível
- melhoria do preview admin para refletir backdrop base do conteúdo
- redução de altura útil do formulário em áreas de borda/espaçamento

## Observações
- frontend e renderer do Hero foram preservados
- a mudança é concentrada no painel administrativo
