# FlashSite Design 0.7.0 — Changelog

## Objetivo
Refatorar a UX/UI do editor de Hero Banner sem alterar schema de dados, shortcode, frontend ou compatibilidade com banners já existentes.

## Entregas
- editor em duas colunas para cada banner
- preview lateral sticky
- device mode único por card (desktop/tablet ou mobile)
- secções colapsáveis com hierarquia visual consistente
- reorganização do fluxo de edição
- estilo e comportamento separados em blocos mais claros
- simplificação do controlo de borda arredondada
- simplificação do controlo de espaçamento interno
- melhoria do preview admin para refletir melhor backdrop e botão base

## Não alterado
- options/meta existentes
- nomes de campos persistidos
- shortcode do Hero
- CSS/JS frontend do Hero
- integração já validada com Elementor
