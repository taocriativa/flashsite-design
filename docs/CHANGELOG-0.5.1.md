# FlashSite Design 0.5.1 — Changelog

## Objetivo
Melhorar a escalabilidade operacional do painel Hero Banners sem reabrir o renderer estabilizado.

## Alterações principais
- gestão visual de múltiplos banners no painel Hero
- botão para adicionar novo banner
- ações por card: duplicar, remover, mover para cima e mover para baixo
- reindexação automática dos campos antes do submit
- título do card sincronizado com o título do banner
- toolbar introdutória para gestão do conjunto de banners

## Notas
Nenhuma alteração foi feita no comportamento estrutural do Hero no frontend.
A base funcional da 0.4.5/0.5.0 foi preservada.
