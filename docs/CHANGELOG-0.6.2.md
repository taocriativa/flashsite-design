# FlashSite Design 0.6.2 — Changelog

## Foco da versão
Consolidação do sistema de UI do painel Hero, sem alterar o renderer estabilizado do frontend.

## Melhorias
- reorganização do fluxo do painel para: mídia → preview → conteúdo → layout → botão → comportamento
- criação de cards internos com contraste leve para reforçar hierarquia visual
- simplificação do bloco de layout por dispositivo com subcards mais claros
- compactação visual dos campos de borda e espaçamento
- melhoria do Live Preview para refletir melhor texto claro e backdrop aplicado
- ajuste da microcopy do painel para orientar o fluxo de edição

## Mantido intacto
- renderer do Hero
- integração com Elementor
- sincronização de altura da linha 0.4.5+
