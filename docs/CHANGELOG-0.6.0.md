# FlashSite Design 0.6.0 — Changelog

## Destaques
- refactor UX do painel Hero com preview canvas por banner
- separação de posicionamento por dispositivo: desktop/tablet e mobile
- separação de espaçamento por dispositivo: desktop/tablet e mobile
- novos controlos do botão por banner: forma, cor de texto, cor de fundo e cores hover
- melhoria da hierarquia visual do painel com grupos funcionais inspirados na referência enviada

## Compatibilidade
- preserva a base funcional do Hero estabilizada na linha 0.4.5+
- não altera a lógica principal de altura do container já validada
