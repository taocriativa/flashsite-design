# FlashSite Design 1.0.1

## Ajustes

- Remove a seção visível “Modelo visual” do editor de banner, preservando o campo internamente para compatibilidade com dados já salvos.
- Renumera o fluxo principal para: Texto do banner, Imagens, Posição e leitura.
- Reestrutura os controles de posição para botões visuais compactos, com ícones de alinhamento horizontal e vertical.
- Reforça o CSS para ocultar os radios nativos e evitar controles colados/desordenados no admin.
- Inverte o contraste visual das seções: cabeçalhos em tom bege e corpo dos campos em branco.
- Mantém os contornos das seções para reforçar a leitura de qual área está sendo editada.
- Remove da área principal o bloco específico de imagem lateral e a nota mobile associada, reduzindo ruído no fluxo do usuário final.

## Compatibilidade

- Mantém o slug `flashsite-design`.
- Mantém os nomes das opções salvas.
- Mantém o shortcode existente.
- Mantém compatibilidade com banners já cadastrados.
