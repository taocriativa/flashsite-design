# FlashSite Design 0.8.8 — Changelog

## Objetivo
Padronizar o alinhamento horizontal da coluna de preview e das ações do editor Hero para que o espaçamento lateral siga a mesma regra visual dos botões de topo e do botão de guardar.

## Alterações
- coluna de preview forçada a ocupar 100% da área reservada no grid
- remoção de compensações laterais no preview card
- alinhamento do bloco de preview com ações de topo e ações finais
- pequena consolidação do espaçamento horizontal do editor Hero
- atualização de versão interna para 0.8.8
