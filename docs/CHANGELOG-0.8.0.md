# FlashSite Design 0.8.0 — Design System base

## Entradas principais
- expansão do módulo **Tema Visual** para funcionar como base de Design System do plugin
- novos campos globais para:
  - tipografia
  - cor de texto
  - estilo global de botão
  - cores globais de botão
- novos toggles por banner para:
  - usar tipografia/cor global
  - usar botão global
- integração desses valores no preview admin e no frontend do Hero

## Mantido intacto
- schema principal do Hero
- shortcode
- renderer estrutural do Hero
- integração com Elementor
